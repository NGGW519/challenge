# 진행 보고서

`aic_work` 작업의 일자별 진행 보고서를 모아두는 디렉토리.

## 작성 규칙
- 파일명: `YYYY-MM-DD.md` (한 날짜에 여러 세션이면 `YYYY-MM-DD-2.md` 등)
- 언어: 한국어. 기술명/명령어/파일경로는 영어 그대로.
- 길이: 한 보고서 200~400줄. 길어지면 핵심만 남기고 나머지는 strategy/ 또는 logs/로 이동.
- 항목: 세션 개요 / 산출물 / 결정 / 검증 / 다음 단계 / 커밋 로그 / 통계.
