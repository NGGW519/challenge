### I2 ─ 토킷 entrypoint / zenoh 구조 분석 (Explore-equivalent, 직접 read)

분석 대상:
- `aic/docker/aic_eval/Dockerfile` — entrypoint 가 `ros2 run rmw_zenoh_cpp rmw_zenohd &` 로 router 띄움 + `exec ros2 launch aic_bringup aic_gz_bringup.launch.py "$@"` 으로 evaluator. 즉 한 컨테이너가 router+eval.
- `aic_model/Dockerfile` — entrypoint 가 `AIC_ROUTER_ADDR` 필수, `ZENOH_CONFIG_OVERRIDE='connect/endpoints=["tcp/'"$AIC_ROUTER_ADDR"'"]'` 자동 주입.
- `aic_zenoh_config.json5` — `access_control.default_permission="allow"`, ACL 은 `*/scoring/**`, `*/aic_engine/**` 등 deny rule + `id_model` subject 에만 적용.
- `should_enable_acl()` — `AIC_ENABLE_ACL` 안 켜면 ACL 자체 off, PASSWD 무시.

핵심 발견 (R1 wrapper 에 반영):
1. 같은 `aic_eval` image 의 `/ws_aic/install` 에 `aic_model` 노드가 이미 colcon build 되어 있어 별도 image 불필요.
2. `--network host` 사용 시 router 주소는 `localhost:7447`.
3. host pixi env 실패 원인 = `ZENOH_CONFIG_OVERRIDE` (connect/endpoints + shm off) + `ZENOH_SESSION_CONFIG_URI` 누락. shm=true 가 호스트↔컨테이너 호환 안 되어 transport 깨지면 lifecycle service 등록도 실패.

### Q1 ─ ACTPlus 추가 패턴을 safety.py / HybridPolicy 에 통합 (A2 ML)

`ACTPlus.py` (이전 시도 검증된 정책) 에서 가져온 패턴:

1. **`ForceAttenuator`** (safety.py 신규) — 12 N × 0.4 s sustained 면 명령 스케일 ×0.35.
   Hard watchdog (18 N × 0.7 s → emergency) 보다 먼저 발동해 −12 N (1 s 누적) 페널티 진입 자체 회피.

2. **`InsertionStabilityDetector`** (safety.py 신규) — TCP 선속도 < 0.01 m/s AND |fz| > 3 N AND |F| < 12 N 가 1.2 s 유지되면 stable contact 으로 판단 → Stage C 조기 종료.
   duration 점수 보존 + jerk 평균 오염 방지.

3. Stage C 루프에서 두 detector 호출:
   - 매 step 시작 시 stability.update() True 면 zero-delta 명령 1회 + return True
   - forward/lateral 명령에 attenuator.update(f_norm) 스케일 적용

테스트 5개 추가 (`test_safety.py`):
- `_FakeClock` 으로 monotonic 시간 모킹
- attenuator: warn 미달, window 진입 후 발동, drop 시 reset 검증
- stability: hold 시간 미달, 흔들리면 reset 검증

→ pytest 81 → 86 PASS, ruff clean.
